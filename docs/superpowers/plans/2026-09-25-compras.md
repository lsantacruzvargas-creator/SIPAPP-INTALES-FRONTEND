# Compras (SC → Licitación → OC a proveedor) — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Nueva vista Compras que agrupa las solicitudes de compra por procesar (RQ de materiales, Servicios Externos y SC manuales), las envía a varios proveedores (PDF), compara cotizaciones y genera la Orden de Compra al proveedor (PDF), más Tipos de Artículo, Empresa cliente/proveedor/ambos y Centros de Costo libres.

**Architecture:** Tres colecciones nuevas encadenadas (`SolicitudCompra` SC-NNNN → `Licitacion` LIC-NNNN → `OrdenCompraProveedor` OCP-NNNN) más el catálogo `TipoArticulo`. Las SC se crean solas al guardar un Requerimiento con ítems de compra o un Servicio Externo; al adjudicar se sincroniza el documento de origen (`estadoPago: "pendiente_pago"`) para no romper Requerimientos ni el reporte de costo por OT. Frontend: página `/compras` con 3 pestañas en tabla, componentes en `Frontend/src/components/compras/`, PDFs con jsPDF.

**Tech Stack:** Node 24 + Express 4 + Mongoose 8 (ESM), MongoDB local; React 19 + Vite + Tailwind 3; jsPDF + jspdf-autotable; xlsx. Tests con el runner nativo `node:test` (sin dependencias nuevas).

**Spec:** `docs/superpowers/specs/2026-09-25-compras-design.md`

## Global Constraints

- Repos git separados: `Backend/` y `Frontend/` (la raíz y `docs/` no están versionados). Antes de la Task 1 crear la rama `feature/compras` en **ambos** repos (`git -C Backend checkout -b feature/compras`, ídem Frontend). Cada commit va en el repo que corresponde.
- Todo mensaje de commit termina con la línea `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>` (en los pasos de commit se omite por brevedad; agregarla con un segundo `-m`).
- MongoDB local: `mongodb://localhost:27017/sipapp-intales` (dev). Los tests usan **otra** base: `mongodb://localhost:27017/sipapp-intales-test` (se borra al inicio de cada archivo de test). Nunca correr tests contra la base de dev.
- Backend en puerto `8080`, API bajo `/api`; frontend `fetchAuth("/ruta")` ya antepone `/api`.
- Todo route handler `async` con `try { … } catch (err) { next(err); }`. Errores de negocio: `res.status(400|403|404).json({ mensaje: "…" })`.
- Códigos en `pre("save")` (último por `_id`, parsear sufijo, +1, `padStart(4, "0")`): `SC-NNNN`, `LIC-NNNN`, `OCP-NNNN`. Guardados en lote siempre secuenciales (`for…of` + `await`), nunca `Promise.all` (race del hook).
- Roles de Compras: `vendedor`, `jefatura`, `admin` (middleware `puedeComprar`). Centros de Costo: `admin`, `jefatura`.
- `OrdenCompra` existente = OC del **cliente**. No se toca. La OC al proveedor es `OrdenCompraProveedor`.
- Nunca `window.alert/confirm/prompt`: usar `ConfirmacionAccion` / `PromptAccion` (modales propios, bug de foco en Electron).
- Comentarios solo para el *porqué* no obvio. Textos de UI en español con tildes.
- Archivos subidos: disco local `Backend/uploads/compras/`, servidos por `/uploads` con auth (no R2).
- IGV 18 %; montos redondeados a 2 decimales; precios unitarios **sin IGV**.
- **Refinamiento vs spec (deliberado):** la pestaña *Compras* filtra en el cliente (mismo patrón que `ListaOrdenesCompra.jsx`); `GET /ordenes-compra-proveedor` devuelve todas las OCP pobladas sin filtros de query. Los archivos de cotización usan un componente compacto propio (`ArchivosProveedor.jsx`) en vez de `TarjetaArchivosRelacionados` (demasiado grande para una columna del cuadro).

```js
import express from "express";
import mongoose from "mongoose";
import jwt from "jsonwebtoken";

process.env.JWT_SECRET = process.env.JWT_SECRET || "test-secret";
const URI = process.env.MONGO_URI_TEST || "mongodb://localhost:27017/sipapp-intales-test";

// Base propia de tests — se borra entera al inicio de cada archivo y se
// recrean los índices (los unique de `codigo` son parte de lo que se prueba).
export async function conectar() {
  if (mongoose.connection.readyState !== 1) await mongoose.connect(URI);
  await mongoose.connection.db.dropDatabase();
  for (const modelo of Object.values(mongoose.models)) await modelo.syncIndexes();
}

export async function limpiar() {
  for (const modelo of Object.values(mongoose.models)) await modelo.deleteMany({});
}

export async function desconectar() {
  await mongoose.disconnect();
}

export function token(rol = "admin", nombre = "Tester") {
  return jwt.sign({ id: new mongoose.Types.ObjectId().toString(), nombre, rol }, process.env.JWT_SECRET);
}

// Monta solo los routers bajo prueba, con el mismo error handler que index.js.
export async function levantar(rutas) {
  const app = express();
  app.use(express.json());
  for (const [base, router] of Object.entries(rutas)) app.use(base, router);
  app.use((err, req, res, next) => {
    res.status(err.status || err.statusCode || 500).json({ mensaje: err.status ? err.message : `Error interno: ${err.message}` });
  });
  const server = await new Promise((resolve) => { const s = app.listen(0, () => resolve(s)); });
  const url = `http://127.0.0.1:${server.address().port}`;

  const api = async (metodo, ruta, { body, rol = "admin", formData } = {}) => {
    const headers = { Authorization: `Bearer ${token(rol)}` };
    if (!formData) headers["Content-Type"] = "application/json";
    const res = await fetch(url + ruta, {
      method: metodo,
      headers,
      body: formData || (body !== undefined ? JSON.stringify(body) : undefined),
    });
    const data = await res.json().catch(() => null);
    return { status: res.status, data };
  };

  return { api, url, cerrar: () => new Promise((r) => server.close(r)) };
}
```

```js
// Clave de comparación para catálogos que se alimentan al vuelo: "Eléctricos",
// "electricos " y "ELÉCTRICOS" tienen que ser el mismo registro.
export const normalizarTexto = (texto = "") =>
  String(texto).normalize("NFD").replace(/[̀-ͯ]/g, "").toLowerCase().replace(/\s+/g, " ").trim();
```

```js
import { Router } from "express";
import authMiddleware from "../middleware/authMiddleware.js";
import TipoArticulo from "../models/TipoArticulo.js";
import { normalizarTexto } from "../utils/normalizarTexto.js";

const router = Router();
router.use(authMiddleware);

router.get("/", async (req, res, next) => {
  try {
    const tipos = await TipoArticulo.find({ activo: true }).sort({ nombre: 1 });
    res.json(tipos);
  } catch (err) { next(err); }
});

// Idempotente: si ya existe uno equivalente (sin tildes/mayúsculas) lo
// devuelve en vez de crear un duplicado.
router.post("/", async (req, res, next) => {
  try {
    const nombre = String(req.body.nombre || "").trim().replace(/\s+/g, " ");
    if (!nombre) return res.status(400).json({ mensaje: "Falta el nombre del tipo de artículo" });
    const nombreNormalizado = normalizarTexto(nombre);
    const existente = await TipoArticulo.findOne({ nombreNormalizado });
    if (existente) return res.json(existente);
    const tipo = await new TipoArticulo({ nombre, nombreNormalizado }).save();
    res.status(201).json(tipo);
  } catch (err) { next(err); }
});

export default router;
```

```js
import SolicitudCompra from "../models/SolicitudCompra.js";
import CentroCosto from "../models/CentroCosto.js";
import Requerimiento from "../models/Requerimiento.js";
import ServicioExterno from "../models/ServicioExterno.js";

// Mismo texto que Requerimientos.jsx muestra para un ítem de compra:
// "Otros" guarda solo { descripcion }; el resto, categoría + campos dinámicos.
export function descripcionItemCompra(item) {
  const campos = item.camposCompra || {};
  if (!item.categoriaMaterial && campos.descripcion) return String(campos.descripcion);
  const detalle = Object.entries(campos).map(([k, v]) => `${k}: ${v}`).join(" · ");
  return [item.categoriaNombre, detalle].filter(Boolean).join(" — ");
}

// Los ítems creados antes del 2026-09-14 no tienen estadoPago — cuentan
// como por procesar.
const pendienteDeCompra = (it) =>
  it.esSolicitudCompra && (it.estadoPago || "por_procesar") === "por_procesar" && it.estado !== "rechazado";

async function centroPorDefecto(tipo) {
  const centro = await CentroCosto.findOne({ tipo, activo: true }, "_id");
  return centro?._id || null;
}

// `soloPendientes` lo usa la migración: RQs viejos pueden tener ítems ya
// procesados/pagados con el flujo anterior que no deben volver a Compras.
export async function crearSCDesdeRequerimiento(requerimiento, { soloPendientes = false } = {}) {
  const items = requerimiento.items.filter((it) => (soloPendientes ? pendienteDeCompra(it) : it.esSolicitudCompra));
  if (items.length === 0) return null;
  const centroMaterial = await centroPorDefecto("material");
  const sc = await new SolicitudCompra({
    origen: "requerimiento",
    requerimiento: requerimiento._id,
    ordenTrabajo: requerimiento.ordenTrabajo,
    solicitadoPor: requerimiento.solicitadoPor,
    observaciones: requerimiento.observaciones || "",
    items: items.map((it) => ({
      tipo: "material",
      descripcion: descripcionItemCompra(it),
      unidad: "und",
      cantidad: it.cantidad,
      tipoArticulo: it.tipoArticulo || null,
      centroCosto: it.centroCosto || centroMaterial,
      origenItemId: it._id,
    })),
  }).save();
  await Requerimiento.updateOne({ _id: requerimiento._id }, { $set: { solicitudCompra: sc._id } });
  return sc;
}

export async function crearSCDesdeServicio(servicio) {
  const sc = await new SolicitudCompra({
    origen: "servicio",
    servicioExterno: servicio._id,
    ordenTrabajo: servicio.ordenTrabajo,
    solicitadoPor: servicio.registradoPor,
    items: [{
      tipo: "servicio",
      descripcion: `${servicio.tipoTrabajo} — ${servicio.material}`,
      unidad: "servicio",
      cantidad: servicio.cantidad,
      tipoArticulo: servicio.tipoArticulo || null,
      centroCosto: servicio.centroCosto || (await centroPorDefecto("servicio")),
    }],
  }).save();
  await ServicioExterno.updateOne({ _id: servicio._id }, { $set: { solicitudCompra: sc._id } });
  return sc;
}
```

```js
// Compras (SC → Licitación → OC a proveedor): vendedor + jefatura + admin
// (decisión del usuario, 2026-09-25 — ver specs/2026-09-25-compras-design.md).
export const ROLES_COMPRAS = ["vendedor", "jefatura", "admin"];

export default function puedeComprar(req, res, next) {
  if (!ROLES_COMPRAS.includes(req.usuario.rol)) {
    return res.status(403).json({ mensaje: "No tienes permiso para operar Compras." });
  }
  next();
}
```

```js
import { Router } from "express";
import authMiddleware from "../middleware/authMiddleware.js";
import puedeComprar from "../middleware/puedeComprar.js";
import SolicitudCompra from "../models/SolicitudCompra.js";
import { notificar } from "../utils/notificar.js";

const router = Router();
router.use(authMiddleware, puedeComprar);

const populate = [
  { path: "ordenTrabajo", select: "codigo numeroOT titulo" },
  { path: "items.tipoArticulo", select: "nombre" },
  { path: "items.centroCosto", select: "nombre" },
];

const ESTADOS = ["por_procesar", "en_licitacion", "adjudicado", "anulado"];

router.get("/", async (req, res, next) => {
  try {
    const filtro = ESTADOS.includes(req.query.estado) ? { "items.estadoCompra": req.query.estado } : {};
    const scs = await SolicitudCompra.find(filtro).populate(populate).sort({ createdAt: -1 });
    res.json(scs);
  } catch (err) { next(err); }
});

// SC manual — gastos generales sin OT (oficina, EPPs, herramientas).
router.post("/", async (req, res, next) => {
  try {
    const items = Array.isArray(req.body.items) ? req.body.items : [];
    if (items.length === 0) return res.status(400).json({ mensaje: "La solicitud debe tener al menos una línea" });
    for (const it of items) {
      if (!["material", "servicio"].includes(it.tipo)) return res.status(400).json({ mensaje: "Cada línea debe ser material o servicio" });
      if (!String(it.descripcion || "").trim()) return res.status(400).json({ mensaje: "Falta la descripción en una línea" });
      if (!(Number(it.cantidad) > 0)) return res.status(400).json({ mensaje: "Todas las líneas necesitan una cantidad válida" });
      if (!it.centroCosto) return res.status(400).json({ mensaje: "Todas las líneas necesitan un centro de costo" });
    }
    const sc = await new SolicitudCompra({
      origen: "manual",
      solicitadoPor: req.usuario.nombre,
      observaciones: String(req.body.observaciones || "").trim(),
      items: items.map((it) => ({
        tipo: it.tipo,
        descripcion: String(it.descripcion).trim(),
        unidad: String(it.unidad || "").trim() || "und",
        cantidad: Number(it.cantidad),
        tipoArticulo: it.tipoArticulo || null,
        centroCosto: it.centroCosto,
      })),
    }).save();
    await sc.populate(populate);
    await notificar(req, { accion: "Creó", entidad: "la Solicitud de Compra", codigo: sc.codigo });
    res.status(201).json(sc);
  } catch (err) { next(err); }
});

async function buscarLinea(req, res) {
  const sc = await SolicitudCompra.findById(req.params.id);
  if (!sc) { res.status(404).json({ mensaje: "Solicitud de compra no encontrada" }); return {}; }
  const linea = sc.items.id(req.params.lineaId);
  if (!linea) { res.status(404).json({ mensaje: "Línea no encontrada" }); return {}; }
  return { sc, linea };
}

router.patch("/:id/lineas/:lineaId", async (req, res, next) => {
  try {
    const { sc, linea } = await buscarLinea(req, res);
    if (!sc) return;
    if (linea.estadoCompra !== "por_procesar") return res.status(400).json({ mensaje: "Solo se puede editar una línea por procesar" });
    if (req.body.tipoArticulo !== undefined) linea.tipoArticulo = req.body.tipoArticulo || null;
    if (req.body.centroCosto !== undefined) linea.centroCosto = req.body.centroCosto || null;
    await sc.save();
    await sc.populate(populate);
    res.json(sc);
  } catch (err) { next(err); }
});

router.patch("/:id/lineas/:lineaId/anular", async (req, res, next) => {
  try {
    const motivo = String(req.body.motivo || "").trim();
    if (!motivo) return res.status(400).json({ mensaje: "El motivo de anulación es obligatorio" });
    const { sc, linea } = await buscarLinea(req, res);
    if (!sc) return;
    if (linea.estadoCompra !== "por_procesar") return res.status(400).json({ mensaje: "Solo se puede anular una línea por procesar" });
    linea.estadoCompra = "anulado";
    linea.motivoAnulacion = motivo;
    await sc.save();
    await sc.populate(populate);
    await notificar(req, { accion: "Anuló una línea de", entidad: "la Solicitud de Compra", codigo: sc.codigo });
    res.json(sc);
  } catch (err) { next(err); }
});

export default router;
```

```js
  if (!this.isNew || this.codigo) return;
  const ultimo = await this.constructor.findOne({}, { codigo: 1 }, { sort: { _id: -1 } });
  const num = ultimo?.codigo ? parseInt(ultimo.codigo.split("-").pop(), 10) + 1 : 1;

});
```

```js
  try {
    const lic = await cargarAbierta(req, res);

    const items = Array.isArray(req.body.items) ? req.body.items : [];
    const proveedores = Array.isArray(req.body.proveedores) ? req.body.proveedores : [];
    const idsProveedores = new Set(lic.proveedores.map((p) => String(p._id)));
    const idsItems = new Set(lic.items.map((i) => String(i._id)));

    for (const it of items) {
      const item = lic.items.id(it._id);
      if (!item) return res.status(400).json({ mensaje: "Ítem no pertenece a la licitación" });
      if (it.descripcion !== undefined) {

        item.descripcion = descripcion;

        item.cantidad = Number(it.cantidad);
      }
      if (it.ganador !== undefined) {
        if (it.ganador && !idsProveedores.has(String(it.ganador))) return res.status(400).json({ mensaje: "Ganador inválido" });
        item.ganador = it.ganador || null;
      }

    for (const p of proveedores) {
      const prov = lic.proveedores.id(p._id);
      if (!prov) return res.status(400).json({ mensaje: "Proveedor no pertenece a la licitación" });

        prov.moneda = p.moneda;

      if (p.precios !== undefined) {
        const precios = (Array.isArray(p.precios) ? p.precios : [])
```

```js
export const round2 = (n) => Math.round(Number(n) * 100) / 100;

export function calcularTotalesOCP(items, afectoIgv) {
  const subtotal = round2(items.reduce((s, it) => s + it.subtotal, 0));
```

```js
// Migración única al activar Compras (spec 2026-09-25). Idempotente.
// Uso: node src/scripts/migrarCompras.js
import "dotenv/config";
import mongoose from "mongoose";
import { pathToFileURL } from "url";
import connectDB from "../config/db.js";
import Empresa from "../models/Empresa.js";
import Requerimiento from "../models/Requerimiento.js";
import ServicioExterno from "../models/ServicioExterno.js";
import { crearSCDesdeRequerimiento, crearSCDesdeServicio } from "../utils/compras.js";

export async function migrarCompras() {
  const clientes = await Empresa.updateMany({ tipo: { $exists: false } }, { $set: { tipo: "cliente" } });
  // Quien ya se usó como proveedor en el flujo anterior pasa a "ambos" — así
  // no desaparece de ningún selector de ventas donde ya se usaba.
  const idsProveedor = [
    ...(await Requerimiento.distinct("items.proveedor")),
    ...(await ServicioExterno.distinct("proveedor")),
  ].filter(Boolean);
  const ambos = await Empresa.updateMany({ _id: { $in: idsProveedor }, tipo: "cliente" }, { $set: { tipo: "ambos" } });

  let scsCreadas = 0;
  const rqs = await Requerimiento.find({ anulado: { $ne: true }, solicitudCompra: null, "items.esSolicitudCompra": true });
  for (const rq of rqs) {
    if (await crearSCDesdeRequerimiento(rq, { soloPendientes: true })) scsCreadas++;
  }
  const servicios = await ServicioExterno.find({ anulado: { $ne: true }, solicitudCompra: null, estadoPago: { $in: ["por_procesar", null] } });
  for (const servicio of servicios) {
    await crearSCDesdeServicio(servicio);
    scsCreadas++;
  }

  return { empresasCliente: clientes.modifiedCount, empresasAmbos: ambos.modifiedCount, scsCreadas };
}

}
```

```js
export const IGV = 0.18;
export const round2 = (n) => Math.round(Number(n) * 100) / 100;

export const money = (valor, moneda = "PEN") =>
  `${moneda === "USD" ? "US$" : "S/"} ${Number(valor || 0).toLocaleString("es-PE", { minimumFractionDigits: 2, maximumFractionDigits: 2 })}`;

export const nombreEmpresa = (e) => (!e ? "" : e.alias ? `${e.alias} — ${e.razonSocial}` : e.razonSocial);

// Los refs llegan como id suelto o como documento poblado según la ruta.
export const idDe = (x) => String(x?._id ?? x ?? "");

export function lineasDeSCs(scs, estado = "por_procesar") {
  return scs.flatMap((sc) => sc.items.filter((l) => l.estadoCompra === estado).map((l) => ({ ...l, sc })));

export function ordenarProveedores(proveedores, tipoArticuloIds) {
  const buscados = new Set(tipoArticuloIds.filter(Boolean).map(idDe));
  const conCoincidencias = proveedores.map((proveedor) => ({
    proveedor,
    coincidencias: (proveedor.tipoArticulos || []).filter((t) => buscados.has(idDe(t))).length,
  }));
  const porNombre = (a, b) => a.proveedor.razonSocial.localeCompare(b.proveedor.razonSocial, "es");
  return {
    sugeridos: conCoincidencias.filter((x) => x.coincidencias > 0).sort((a, b) => b.coincidencias - a.coincidencias || porNombre(a, b)),
    otros: conCoincidencias.filter((x) => x.coincidencias === 0).sort(porNombre),
    totalTipos: buscados.size,
  };
}

export function totalesOCP(items, afectoIgv = true) {
  const subtotal = round2(items.reduce((s, it) => s + Number(it.cantidad || 0) * Number(it.precioUnitario || 0), 0));
  const igv = afectoIgv ? round2(subtotal * IGV) : 0;
  return { subtotal, igv, total: round2(subtotal + igv) };
}

// USD se convierte a soles SOLO para decidir cuál es más barato.
export function proveedorMasBarato(proveedores, itemId, tipoCambio) {
  let mejor = null;
  for (const p of proveedores) {
    const precio = p.precios?.find((x) => idDe(x.itemId) === idDe(itemId))?.precioUnitario;
    if (precio === undefined || precio === null || precio === "") continue;
    const enSoles = p.moneda === "USD" ? Number(precio) * tipoCambio : Number(precio);
    if (!mejor || enSoles < mejor.enSoles) mejor = { id: idDe(p._id), enSoles };
  }
  return mejor?.id ?? null;
}

export const FILTROS_VACIOS = { codigo: "", proveedor: "", texto: "", tipoArticulo: "", centroCosto: "", desde: "", hasta: "", estado: "" };

const fechaLima = (d) => new Intl.DateTimeFormat("en-CA", { timeZone: "America/Lima" }).format(new Date(d));
const contiene = (valor, q) => String(valor || "").toLowerCase().includes(q.trim().toLowerCase());

function itemCumple(it, f) {
  if (f.texto && !contiene(it.descripcion, f.texto)) return false;
  if (f.tipoArticulo && idDe(it.tipoArticulo) !== f.tipoArticulo) return false;
  if (f.centroCosto && idDe(it.centroCosto) !== f.centroCosto) return false;
  return true;
}

export function filtrarOCPs(ocps, f) {
  const filtraItems = f.texto || f.tipoArticulo || f.centroCosto;
  return ocps.filter((o) => {
    if (f.codigo && !contiene(o.codigo, f.codigo)) return false;
    if (f.proveedor && idDe(o.proveedor) !== f.proveedor) return false;
    if (f.estado === "vigente" && o.anulada) return false;
    if (f.estado === "anulada" && !o.anulada) return false;
    if (f.desde && fechaLima(o.fecha) < f.desde) return false;
    if (f.hasta && fechaLima(o.fecha) > f.hasta) return false;
    if (filtraItems && !o.items.some((it) => itemCumple(it, f))) return false;
    return true;
  });
}

export function aplanarItemsOCP(ocps, f) {
  return filtrarOCPs(ocps, f).flatMap((ocp) => ocp.items.filter((it) => itemCumple(it, f)).map((it) => ({ ...it, ocp })));
}
```

```jsx
import { useState, useEffect } from "react";
import { fetchAuth } from "../utils/fetchAuth";

const normalizar = (t = "") => t.normalize("NFD").replace(/[̀-ͯ]/g, "").toLowerCase().replace(/\s+/g, " ").trim();
const porNombre = (a, b) => a.nombre.localeCompare(b.nombre, "es");
const INP = "w-full border border-gray-200 rounded-lg px-3 py-2 text-sm focus:outline-none focus:ring-2 focus:ring-blue-300";

// Buscador del catálogo Tipos de Artículo con alta al vuelo ("+ Agregar").
// Si el padre ya cargó el catálogo lo pasa en `tipos` y recibe los nuevos
// por `onTipoCreado`; si no, el componente lo carga solo.
export default function SelectorTipoArticulo({ value, onChange, multiple = false, tipos: tiposPadre, onTipoCreado, placeholder = "Buscar o agregar tipo…" }) {
  const [tiposPropios, setTiposPropios] = useState([]);
  const tipos = tiposPadre ?? tiposPropios;
  const [texto, setTexto] = useState("");
  const [abierto, setAbierto] = useState(false);
  const [creando, setCreando] = useState(false);
  const [error, setError] = useState("");

  useEffect(() => {
    if (tiposPadre) return;
    fetchAuth("/tipos-articulo").then((r) => (r.ok ? r.json() : [])).then(setTiposPropios);
  }, [tiposPadre]);

  const seleccionados = multiple ? (value || []).map(String) : value ? [String(value)] : [];
  const q = normalizar(texto);
  const sugerencias = tipos
    .filter((t) => !seleccionados.includes(String(t._id)) && (!q || normalizar(t.nombre).includes(q)))
    .slice(0, 8);
  const existeExacto = tipos.some((t) => normalizar(t.nombre) === q);
  const nombreDe = (id) => tipos.find((t) => String(t._id) === id)?.nombre || "…";

  const elegir = (tipo) => {
    if (multiple) onChange([...seleccionados, String(tipo._id)]);
    else onChange(String(tipo._id), tipo);
    setTexto("");
    setAbierto(false);
  };

  const quitar = (id) => (multiple ? onChange(seleccionados.filter((x) => x !== id)) : onChange("", null));

  const crear = async () => {
    setCreando(true);
    setError("");
    const r = await fetchAuth("/tipos-articulo", { method: "POST", body: JSON.stringify({ nombre: texto }) });
    setCreando(false);
    if (!r.ok) {
      const d = await r.json().catch(() => ({}));
      setError(d.mensaje || "No se pudo crear el tipo de artículo");
      return;
    }
    const tipo = await r.json();
    if (!tipos.some((t) => t._id === tipo._id)) {
      if (tiposPadre) onTipoCreado?.(tipo);
      else setTiposPropios((prev) => [...prev, tipo].sort(porNombre));
    }
    elegir(tipo);
  };

  const mostrarElegido = !multiple && seleccionados.length > 0 && !abierto;

  return (
    <div className="relative">
      {multiple && seleccionados.length > 0 && (
        <div className="flex flex-wrap gap-1 mb-1.5">
          {seleccionados.map((id) => (
            <span key={id} className="inline-flex items-center gap-1 text-xs bg-indigo-50 text-indigo-700 rounded-full px-2 py-0.5">
              {nombreDe(id)}
              <button type="button" onClick={() => quitar(id)} className="hover:text-red-500">✕</button>
            </span>
          ))}
        </div>
      )}
      {mostrarElegido ? (
        <div className={`${INP} flex items-center justify-between gap-2 cursor-pointer`} onClick={() => setAbierto(true)}>
          <span className="truncate">{nombreDe(seleccionados[0])}</span>
          <button type="button" onClick={(e) => { e.stopPropagation(); quitar(seleccionados[0]); }}
            className="text-gray-300 hover:text-red-500">✕</button>
        </div>
      ) : (
        <input
          value={texto}
          autoFocus={!multiple && abierto}
          onChange={(e) => { setTexto(e.target.value); setAbierto(true); }}
          onFocus={() => setAbierto(true)}
          onBlur={() => setAbierto(false)}
          placeholder={placeholder}
          className={INP}
        />
      )}
      {abierto && (sugerencias.length > 0 || (q && !existeExacto)) && (
        <ul className="absolute z-[90] left-0 right-0 mt-1 bg-white border border-gray-200 rounded-lg shadow-lg max-h-56 overflow-y-auto text-sm">
          {sugerencias.map((t) => (
            <li key={t._id}>
              <button type="button" onMouseDown={(e) => e.preventDefault()} onClick={() => elegir(t)}
                className="w-full text-left px-3 py-1.5 hover:bg-gray-50">{t.nombre}</button>
            </li>
          ))}
          {q && !existeExacto && (
            <li>
              <button type="button" disabled={creando} onMouseDown={(e) => e.preventDefault()} onClick={crear}
                className="w-full text-left px-3 py-1.5 text-blue-600 hover:bg-blue-50 disabled:opacity-50">
                {creando ? "Agregando…" : `+ Agregar "${texto.trim()}"`}
              </button>
            </li>
          )}
        </ul>
      )}
      {error && <p className="text-[11px] text-red-500 mt-1">{error}</p>}
    </div>
  );
}
```

```js
export async function encabezado(doc, titulo, codigo, fecha) {
  const emisorRes = await fetchAuth("/cotizaciones/emisor");
  const emisor = emisorRes.ok ? await emisorRes.json() : { ruc: "", razonSocial: "" };

  const PAGE_W = doc.internal.pageSize.getWidth();

  if (logo) {
    doc.addImage(logo, formatoImagen(logo), M, M, ALTO_LOGO * (logo.naturalWidth / logo.naturalHeight), ALTO_LOGO);
  } else {
    doc.setFont("helvetica", "bold");

  doc.setTextColor(...NAVY);
```

```jsx
    !yaInvitados.has(String(p._id)) && (!q || [p.razonSocial, p.alias, p.ruc].some((v) => v?.toLowerCase().includes(q)))
  );
  const { sugeridos, otros, totalTipos } = ordenarProveedores(visibles, items.map((i) => i.tipoArticulo));

    return s;
  });

    const d = await r.json().catch(() => ({}));
    setError(d.mensaje || mensaje);
    setEnviando(false);

        <div className="flex items-center justify-between px-6 py-4 border-b border-gray-100 shrink-0">
          <div>

            <p className="text-xs text-gray-400 mt-0.5">{items.length} ítem{items.length !== 1 ? "s" : ""} · se descargará un PDF por proveedor</p>
          </div>

        </div>

        <div className="flex-1 overflow-y-auto p-6 space-y-4">
          <ul className="text-xs text-gray-600 bg-gray-50 rounded-lg p-3 space-y-1 max-h-32 overflow-y-auto">
            {items.map((it) => (
              <li key={it._id}>

              </li>
```

```jsx
export default function TablaPorProcesar({ catalogos, onTipoCreado, onEnviado }) {
  const [scs, setScs] = useState([]);
  const [cargando, setCargando] = useState(true);
  const [seleccion, setSeleccion] = useState(() => new Set());
  const [filtros, setFiltros] = useState({ texto: "", tipoArticulo: "", tipo: "" });
  const [nuevaAbierta, setNuevaAbierta] = useState(false);
  const [enviarAbierto, setEnviarAbierto] = useState(false);

  const [creandoTipoPara, setCreandoTipoPara] = useState(null);
  const [procesando, setProcesando] = useState(false);

    if (r.ok) setScs(await r.json());
```

```jsx
import { useState } from "react";
import { fetchAuth, uploadAuth, abrirArchivoProtegido } from "../../utils/fetchAuth";

const ACCEPT = [
  "image/jpeg", "image/png", "image/webp",
  "application/pdf",
  "application/msword",
  "application/vnd.openxmlformats-officedocument.wordprocessingml.document",
  "application/vnd.ms-excel",
  "application/vnd.openxmlformats-officedocument.spreadsheetml.sheet",
].join(",");

// Versión compacta de TarjetaArchivosRelacionados para caber en una columna
// del cuadro comparativo: cotizaciones que devolvió un proveedor.
export default function ArchivosProveedor({ licitacionId, proveedor, puedeSubir = true, puedeBorrar = false, onCambio }) {
  const [subiendo, setSubiendo] = useState(false);
  const [error, setError] = useState("");
  const base = `/licitaciones/${licitacionId}/proveedores/${proveedor._id}/archivos`;

  const subir = async (fileList) => {
    const files = Array.from(fileList || []);
    if (files.length === 0) return;
    setSubiendo(true);
    setError("");
    let ultima = null;
    // Secuencial: cada subida hace push sobre el mismo documento.
    for (const file of files) {
      const fd = new FormData();
      fd.append("archivo", file);
      const r = await uploadAuth(base, fd);
      if (r.ok) ultima = await r.json();
      else setError(`No se pudo subir "${file.name}" — formato o tamaño no permitido (máx. 20 MB).`);
    }
    setSubiendo(false);
    if (ultima) onCambio(ultima);
  };

  const borrar = async (archivo) => {
    const r = await fetchAuth(`${base}/${archivo._id}`, { method: "DELETE" });
    if (r.ok) onCambio(await r.json());
    else {
      const d = await r.json().catch(() => ({}));
      setError(d.mensaje || "No se pudo quitar el archivo.");
    }
  };

  return (
    <div className="space-y-1">
      {(proveedor.archivos || []).map((a) => (
        <div key={a._id} className="flex items-center gap-1 text-xs">
          <button type="button" onClick={() => abrirArchivoProtegido(a.url)} title={a.nombre}
            className="text-blue-600 hover:underline truncate max-w-[170px] text-left">📎 {a.nombre}</button>
          {puedeBorrar && <button type="button" onClick={() => borrar(a)} className="text-gray-300 hover:text-red-500">✕</button>}
        </div>
      ))}
      {puedeSubir && (
        <label className={`inline-block text-xs text-cyan-700 ${subiendo ? "opacity-60" : "hover:underline cursor-pointer"}`}>
          {subiendo ? "Subiendo…" : "+ Adjuntar cotización"}
          <input type="file" multiple accept={ACCEPT} className="hidden" disabled={subiendo}
            onChange={(e) => { subir(e.target.files); e.target.value = ""; }} />
        </label>
      )}
      {error && <p className="text-[11px] text-red-500">{error}</p>}
    </div>
  );
}
```

```jsx
// el usuario está tipeando ("12." → 12).
function borradorDesde(lic) {
  return {
    items: Object.fromEntries(lic.items.map((i) => [i._id, {
      descripcion: i.descripcion, cantidad: String(i.cantidad), ganador: i.ganador ? String(i.ganador) : "",
    }])),
    proveedores: Object.fromEntries(lic.proveedores.map((p) => [p._id, {
      moneda: p.moneda,
      observaciones: p.observaciones || "",
      precios: Object.fromEntries(p.precios.map((x) => [String(x.itemId), String(x.precioUnitario)])),
    }])),
  };
}

  const [lic, setLic] = useState(null);
  const [borrador, setBorrador] = useState(null);

    fetchAuth(`/licitaciones/${licitacionId}`).then(async (r) => {
      if (!r.ok) return;
      const l = await r.json();
      setLic(l);
      setBorrador(borradorDesde(l));
    });
  }, [licitacionId]);

  if (!lic || !borrador) {
    return (

  const setPrecio = (provId, itemId, valor) => setBorrador((b) => ({
    ...b,
    proveedores: { ...b.proveedores, [provId]: { ...b.proveedores[provId], precios: { ...b.proveedores[provId].precios, [itemId]: valor } } },
  }));

    setGuardando(true);
    setError("");

        descripcion: borrador.items[i._id].descripcion,

                <th className="px-2 py-2 text-left text-xs text-gray-500 border-b">SC</th>
                <th className="px-2 py-2 text-left text-xs text-gray-500 border-b min-w-[240px]">Descripción</th>

                        <option value="PEN">S/</option>
```

```js
export async function exportarOrdenCompraProveedorPdf(ocp) {
  const doc = new jsPDF();
  const PAGE_W = doc.internal.pageSize.getWidth();
  const m = (v) => money(v, ocp.moneda);
  let y = await encabezado(doc, "ORDEN DE COMPRA", ocp.codigo, ocp.fecha);
  y = bloqueDatos(doc, y, [
    ["Proveedor", ocp.proveedorRazonSocial || "—"],
    ["RUC", ocp.proveedorRuc || "—"],
    ["Dirección", ocp.proveedorDireccion || "—"],
    ["Forma de pago", ocp.formaPago || "—"],
    ["Lugar de entrega", ocp.lugarEntrega || "—"],
    ["Fecha de entrega", ocp.fechaEntrega ? formatearFecha(ocp.fechaEntrega) : "—"],
    ["Moneda", ocp.moneda === "USD" ? "Dólares (US$)" : "Soles (S/)"],
  ]);
  autoTable(doc, {
    ...ESTILO_TABLA,
    startY: y,
    head: [["#", "Descripción", "Und.", "Cant.", "P. unit.", "Subtotal"]],
    body: ocp.items.map((it, i) => [i + 1, it.descripcion, it.unidad, it.cantidad, m(it.precioUnitario), m(it.subtotal)]),
    columnStyles: {
      0: { cellWidth: 8, halign: "center" }, 2: { cellWidth: 16, halign: "center" }, 3: { cellWidth: 16, halign: "right" },
      4: { cellWidth: 28, halign: "right" }, 5: { cellWidth: 30, halign: "right" },
    },
  });
  autoTable(doc, {
    startY: doc.lastAutoTable.finalY + 2,
    margin: { left: PAGE_W - M - 74, right: M },
    theme: "plain",
    body: [["Subtotal", m(ocp.subtotal)], [ocp.afectoIgv ? "IGV 18%" : "No afecto a IGV", m(ocp.igv)], ["TOTAL", m(ocp.total)]],
    styles: { fontSize: 9, cellPadding: 1.2 },
    columnStyles: { 0: { fontStyle: "bold" }, 1: { halign: "right" } },
    didParseCell: (d) => { if (d.row.index === 2) d.cell.styles.fontStyle = "bold"; },
  });
  y = doc.lastAutoTable.finalY + 6;
  if (ocp.observaciones) {
    doc.setFont("helvetica", "bold");
    doc.setFontSize(9);
    doc.text("Observaciones:", M, y);
    doc.setFont("helvetica", "normal");
    doc.text(doc.splitTextToSize(ocp.observaciones, PAGE_W - M * 2), M, y + 5);
  }
  doc.save(`${ocp.codigo}.pdf`);
}
```
